🧪 推算方式

照片中找出雞蛋區域，計算紅色通道與灰階亮度，和 0 分鐘參考照作比值，再對照原始資料的 R、灰度及透光率曲線，以分段線性插值估計「等效加熱時間」。熟化階段再參考三層熱傳導與熟化動力學的理論預測。

📋 怎樣拍會較準？

使用相同雞蛋擺放方式及穩定紅光源，關閉自動曝光、白平衡或濾鏡（如裝置允許），固定手機與光源距離，並先拍 0 分鐘未煮雞蛋作參考。蛋殼顏色、尺寸及手機拍攝設定不同，都可能造成顯著偏差。
